RBI Corpus Project Notes
========================

Goal
----
Build a small RBI regulatory/legal corpus pipeline for downloading RBI PDFs,
extracting text, cleaning it, and producing JSONL files for downstream RAG,
rule generation, or training workflows.

Current Pipeline
----------------
1. Store RBI PDF metadata and direct PDF URLs in:
   rbi_corpus/data/raw_pdfs/links.json

2. Download PDFs into:
   rbi_corpus/data/raw_pdfs/

3. Extract and clean text into:
   rbi_corpus/data/extracted/rbi_circulars.jsonl

4. Build processed or chunked JSONL into:
   rbi_corpus/data/processed/rbi_circulars_processed.jsonl

Scripts
-------
- rbi_corpus/scripts/download_links.py
  Downloads PDFs from links.json.

- rbi_corpus/scripts/extract_text.py
  Extracts text from downloaded PDFs using pdfplumber first, with PyMuPDF fallback.

- rbi_corpus/scripts/clean_text.py
  Shared text cleaning helper.

- rbi_corpus/scripts/build_jsonl.py
  Builds processed JSONL and supports chunking.

Run Commands
------------
Use python3 if python is unavailable.

cd rbi_corpus/scripts
python3 download_links.py
python3 extract_text.py
python3 build_jsonl.py

Optional chunked output:
python3 build_jsonl.py --chunk --chunk-size 1200

  https://rbidocs.rbi.org.in/rdocs/notification/PDFs/GUIDELINESDIGITALLENDINGD5C35A71D8124A0E92AEB940A7D25BB3.PDF
